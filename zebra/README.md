# Zebra BrowserPrint JS (not included)

Z Browser Print was made compatible with Zebra's `BrowserPrint-3.1.250.min.js`.
That file belongs to Zebra Technologies and is not redistributed here.

If you need it for testing, get it from Zebra's Browser Print SDK, or save it from a
web app that already uses it. Put it in this folder; git ignores it.
